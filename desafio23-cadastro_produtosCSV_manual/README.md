# Desafio 23 - Cadastro de Produtos em CSV

## 📖 Sobre

Neste desafio foi desenvolvido um sistema para cadastrar produtos em um arquivo CSV criado manualmente utilizando Python.

O programa grava um cabeçalho, cadastra produtos e posteriormente realiza a leitura do arquivo para exibir todas as informações armazenadas.

---

## Funcionalidades

- criar um arquivo CSV;
- escrever o cabeçalho;
- cadastrar três produtos;
- armazenar nome, preço e estoque;
- formatar valores monetários com duas casas decimais;
- ler o arquivo linha por linha;
- exibir todos os registros cadastrados.

---

## Estrutura do arquivo

Após a execução, o arquivo possui a seguinte estrutura:

```csv
Nome;Preco;Estoque
Notebook;1800.00;5
Mouse;80.00;20
Teclado;150.00;10
```

## Fluxo do programa

1. Criar o arquivo CSV.
2. Escrever o cabeçalho.
3. Solicitar o cadastro de três produtos.
4. Salvar os dados no arquivo.
5. Fechar o arquivo.
6. Abrir novamente em modo leitura.
7. Exibir todos os registros.
