# Aula 27 - Produto com maior e menor estoque

## Sobre

Neste desafio foi desenvolvido um programa capaz de analisar um arquivo CSV e identificar automaticamente:

- o produto com maior estoque;
- o produto com menor estoque.

Toda a análise é realizada percorrendo o arquivo apenas uma única vez.

---

## Funcionalidades

- leitura de arquivos CSV;
- utilização do `csv.DictReader()`;
- conversão do estoque para inteiro;
- identificação do maior estoque;
- identificação do menor estoque;
- exibição dos resultados.

---

## Fluxo do programa

1. Abrir o arquivo CSV.
2. Ler os registros utilizando `DictReader`.
3. Converter o estoque para `int`.
4. Comparar o estoque atual com o maior encontrado.
5. Comparar o estoque atual com o menor encontrado.
6. Atualizar as variáveis de referência quando necessário.
7. Exibir os resultados.

## Aprendizados

Durante este desafio foi possível compreender como identificar automaticamente o maior e o menor valor dentro de um conjunto de dados.

Também foi reforçado o conceito de que algumas verificações precisam ser independentes, utilizando dois `if` em vez de `elif`.
