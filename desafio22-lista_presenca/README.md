# Desafio 21 - Lista de Presença

## 📖 Sobre

Neste desafio foi desenvolvido um sistema simples para registrar uma lista de presença utilizando arquivos de texto.

Os nomes digitados são armazenados em um arquivo `.txt` e posteriormente exibidos linha por linha.

---

## Funcionalidades

- cadastrar cinco convidados;
- salvar os nomes em um arquivo;
- manter os registros anteriores;
- ler o arquivo;
- exibir cada convidado individualmente.

---

---

## Funcionamento

O programa realiza as seguintes etapas:

1. Solicita cinco nomes.

2. Salva cada nome em uma linha do arquivo.

3. Fecha o arquivo.

4. Reabre em modo leitura.

5. Percorre o arquivo linha por linha.

6. Exibe todos os convidados cadastrados.

---

## Exemplo de saída

```
========== C O N V I D A D O S ==========

Carlos

Maria

João

Pedro

Ana
```
